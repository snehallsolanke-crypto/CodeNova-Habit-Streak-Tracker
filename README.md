
# Personal Habit & Daily Streak Tracker

## About the Project
A Python-based Habit Tracker application that helps users create and manage daily habits, track completed days, and monitor their progress.

## Features
- Add New Habit
- View All Habits
- Mark Habit as Completed
- Delete Habit
- View Current Habit Streak
- Monthly Completion Rate
- Prevent Duplicate Daily Check-ins
- Save Data using JSON

## Technologies Used
- Python
- JSON
- DateTime Module

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   py habit_tracker.py

## Data Storage
Habit data is stored in habits.json.
